JS LegalTech Control Light - Corrección del Portal del Cliente

Correcciones incluidas:
1. El portal espera a que Firebase Authentication restaure la sesión antes de consultar Firestore.
2. Las reglas permiten reconocer al cliente por authUid o por el correo autenticado.
3. Al iniciar sesión, el sistema completa automáticamente authUid en clientes anteriores.
4. El rol Cliente ya no intenta sincronizar las colecciones generales clientes y personal.
5. La línea del tiempo usa las actuaciones obtenidas directamente del asunto sincronizado.
6. Se eliminó el campo de contraseña del formulario de cliente. La contraseña se crea mediante el correo seguro de Firebase.

IMPORTANTE:
El archivo firestore.rules fue corregido, pero las reglas deben publicarse en Firebase para que el cambio funcione.

Desde la carpeta del proyecto, si Firebase CLI ya está configurado:

firebase deploy --only firestore:rules

Después:
- Cierra la sesión del cliente.
- Recarga la página.
- Inicia sesión otra vez con el correo y contraseña creados mediante el enlace de Firebase.
- Abre el expediente y selecciona Ver Bitácora.

El campo clienteId de cada asunto debe seguir coincidiendo con el ID del documento correspondiente en la colección clientes.
